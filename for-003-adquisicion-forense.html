Fundamentos

ESTADO: DOCUMENTADO

[ FUNDAMENTO ]

Adquisición Forense

DEFINICIÓN: Proceso técnico mediante el cual se obtiene una copia controlada de la evidencia digital para su posterior análisis.

IMPORTANCIA: Permite preservar la información original evitando modificaciones que comprometan su valor probatorio.

APLICACIÓN PRÁCTICA: Realizar copias verificables de discos, dispositivos móviles, servidores o medios de almacenamiento utilizando procedimientos documentados.

[ FUNDAMENTO ]

Evidencia Original

DEFINICIÓN: Fuente primaria de información digital obtenida durante una investigación forense.

IMPORTANCIA: Constituye el elemento original sobre el cual se fundamenta toda la validez técnica del análisis.

APLICACIÓN PRÁCTICA: Identificar, preservar y documentar el dispositivo o sistema que contiene la evidencia antes de cualquier intervención.

[ FUNDAMENTO ]

Copia de Trabajo

DEFINICIÓN: Réplica de la evidencia utilizada para realizar análisis sin intervenir sobre el soporte original.

IMPORTANCIA: Reduce el riesgo de alterar o contaminar la evidencia durante la investigación.

APLICACIÓN PRÁCTICA: Realizar búsquedas, recuperación de archivos y análisis técnico únicamente sobre la copia forense obtenida.

[ FUNDAMENTO ]

Procedimiento

DEFINICIÓN: Conjunto de pasos técnicos y documentales aplicados para obtener evidencia digital de manera controlada.

IMPORTANCIA: Garantiza la integridad, trazabilidad y validez de la evidencia obtenida.

APLICACIÓN PRÁCTICA: Documentar identificación, adquisición, verificación mediante hash, almacenamiento y análisis de la evidencia.

[ SECCIÓN 02 ]

Métodos de Adquisición

ESTADO: DOCUMENTADO

[ MÉTODO ]

Live Acquisition

DEFINICIÓN: Obtención de evidencia mientras el sistema permanece encendido y operativo.

IMPORTANCIA: Permite capturar información volátil que desaparecería al apagar el equipo.

APLICACIÓN PRÁCTICA: Recolección de memoria RAM, conexiones activas, procesos en ejecución y sesiones abiertas.

[ MÉTODO ]

Dead Acquisition

DEFINICIÓN: Obtención de evidencia digital con el sistema apagado o desconectado.

IMPORTANCIA: Reduce el riesgo de modificaciones accidentales sobre la información almacenada.

APLICACIÓN PRÁCTICA: Extracción de discos para generar imágenes forenses controladas en laboratorio.

[ MÉTODO ]

Lógica

DEFINICIÓN: Adquisición de archivos, carpetas y datos visibles mediante herramientas del sistema operativo.

IMPORTANCIA: Permite obtener información específica sin copiar la totalidad del dispositivo.

APLICACIÓN PRÁCTICA: Recolección de documentos, correos electrónicos, registros y bases de datos.

[ MÉTODO ]

Física

DEFINICIÓN: Obtención completa de todos los sectores de almacenamiento del dispositivo.

IMPORTANCIA: Permite recuperar datos eliminados y espacio no asignado.

APLICACIÓN PRÁCTICA: Creación de imágenes bit a bit para análisis forense exhaustivo.

Imagen Forense

[ IMAGEN FORENSE ]

Bit a Bit

DEFINICIÓN: Copia exacta de todos los sectores de almacenamiento, incluyendo espacio libre y datos eliminados.

IMPORTANCIA: Garantiza una réplica íntegra del soporte original para análisis posteriores.

APLICACIÓN PRÁCTICA: Generación de imágenes forenses de discos rígidos, SSD o dispositivos extraíbles.

[ IMAGEN FORENSE ]

Clonación

DEFINICIÓN: Copia exacta de un dispositivo hacia otro soporte de almacenamiento.

IMPORTANCIA: Permite trabajar sobre una réplica sin comprometer la evidencia original.

APLICACIÓN PRÁCTICA: Migración controlada de discos para análisis en laboratorio.

[ IMAGEN FORENSE ]

Integridad

DEFINICIÓN: Garantía de que la imagen forense conserva exactamente el contenido original.

IMPORTANCIA: Mantiene el valor probatorio de la evidencia.

APLICACIÓN PRÁCTICA: Verificación mediante algoritmos hash antes y después de la adquisición.

[ IMAGEN FORENSE ]

Almacenamiento

DEFINICIÓN: Resguardo seguro de imágenes forenses obtenidas durante la investigación.

IMPORTANCIA: Evita pérdidas, corrupción o accesos no autorizados.

APLICACIÓN PRÁCTICA: Conservación en servidores protegidos o medios dedicados de evidencia.

[ SECCIÓN 04 ]

Hash y Verificación

ESTADO: DOCUMENTADO

[ HASH ]

MD5

DEFINICIÓN: Algoritmo hash utilizado para generar una huella digital única de un archivo o soporte.

IMPORTANCIA: Permite verificar que la evidencia no sufrió modificaciones durante su manipulación.

APLICACIÓN PRÁCTICA: Comparar valores hash antes y después de cada procedimiento forense.

[ HASH ]

SHA-1

DEFINICIÓN: Algoritmo hash utilizado históricamente para validar integridad de archivos.

IMPORTANCIA: Permite detectar modificaciones en la evidencia digital.

APLICACIÓN PRÁCTICA: Comparación de valores hash durante procedimientos forenses.

[ HASH ]

SHA-256

DEFINICIÓN: Algoritmo criptográfico ampliamente utilizado para verificación de integridad.

IMPORTANCIA: Ofrece mayor seguridad frente a colisiones que algoritmos más antiguos.

APLICACIÓN PRÁCTICA: Validación de imágenes forenses y archivos críticos.

[ HASH ]

Verificación

DEFINICIÓN: Proceso de comprobación de integridad mediante comparación de hashes.

IMPORTANCIA: Confirma que la evidencia no fue alterada.

APLICACIÓN PRÁCTICA: Verificación previa y posterior a transferencias o análisis.

Herramientas Forenses

ESTADO: DOCUMENTADO

[ HERRAMIENTA ]

FTK Imager

DESCRIPCIÓN: Herramienta forense utilizada para adquirir y visualizar evidencia digital sin alterar el soporte original.

FUNCIÓN: Crear imágenes forenses y obtener información preliminar de dispositivos de almacenamiento.

VENTAJA: Amplio uso profesional y compatibilidad con múltiples formatos de evidencia.

[ HERRAMIENTA ]

Autopsy

DESCRIPCIÓN: Plataforma de análisis forense digital basada en código abierto utilizada para examinar discos, imágenes forenses y sistemas de archivos.

FUNCIÓN: Permite recuperar archivos, analizar actividad del sistema y generar informes periciales.

VENTAJA: Amplio uso académico y profesional, integración con The Sleuth Kit y soporte para múltiples formatos de evidencia.

[ HERRAMIENTA ]

EnCase

DESCRIPCIÓN: Suite profesional utilizada en investigaciones forenses para adquisición, análisis y presentación de evidencia digital.

FUNCIÓN: Analizar discos, dispositivos y sistemas complejos preservando la integridad de la evidencia.

VENTAJA: Amplia aceptación en ámbitos judiciales y corporativos a nivel internacional.

[ HERRAMIENTA ]

dd

DESCRIPCIÓN: Herramienta de línea de comandos utilizada para copiar datos de bajo nivel y generar imágenes forenses bit a bit.

FUNCIÓN: Crear copias exactas de dispositivos de almacenamiento sin depender de interfaces gráficas.

VENTAJA: Ligera, ampliamente disponible en sistemas Linux y muy utilizada en laboratorios forenses.

[ PRESERVACIÓN ]

Soporte Original

DEFINICIÓN: Dispositivo o medio donde se encuentra inicialmente la evidencia digital.

IMPORTANCIA: Constituye la fuente primaria de información y debe preservarse sin alteraciones.

APLICACIÓN PRÁCTICA: Mantener el dispositivo aislado, identificado y protegido durante toda la investigación.

[ PRESERVACIÓN ]

Bloqueador de Escritura

DEFINICIÓN: Dispositivo o mecanismo que impide modificaciones sobre el soporte original.

IMPORTANCIA: Protege la evidencia durante la adquisición.

APLICACIÓN PRÁCTICA: Lectura segura de discos rígidos y dispositivos USB.

[ PRESERVACIÓN ]

Almacenamiento Seguro

DEFINICIÓN: Resguardo controlado de soportes y copias forenses.

IMPORTANCIA: Evita accesos no autorizados o daños accidentales.

APLICACIÓN PRÁCTICA: Conservación en depósitos seguros o servidores restringidos.

[ PRESERVACIÓN ]

Copias de Respaldo

DEFINICIÓN: Réplicas adicionales de evidencia obtenidas para contingencias.

IMPORTANCIA: Garantizan disponibilidad ante fallas o incidentes.

APLICACIÓN PRÁCTICA: Mantener copias verificadas en ubicaciones separadas.

Validez Técnica

ESTADO: DOCUMENTADO

[ VALIDEZ TÉCNICA ]

Integridad

DEFINICIÓN: Garantía de que la evidencia conserva exactamente el mismo contenido desde su adquisición.

IMPORTANCIA: Permite demostrar que el análisis se realizó sobre información auténtica.

APLICACIÓN PRÁCTICA: Verificación mediante hashes y registros documentados de custodia.

[ VALIDEZ TÉCNICA ]

Reproducibilidad

DEFINICIÓN: Capacidad de repetir un procedimiento obteniendo resultados consistentes.

IMPORTANCIA: Aumenta la confiabilidad del análisis.

APLICACIÓN PRÁCTICA: Documentar herramientas, configuraciones y metodología empleada.

[ VALIDEZ TÉCNICA ]

Documentación

DEFINICIÓN: Registro detallado de todas las actividades realizadas durante la investigación.

IMPORTANCIA: Permite auditar y reconstruir el procedimiento.

APLICACIÓN PRÁCTICA: Actas, informes técnicos y registros de custodia.

[ VALIDEZ TÉCNICA ]

Trazabilidad

DEFINICIÓN: Seguimiento completo de la evidencia desde su obtención hasta su presentación.

IMPORTANCIA: Permite demostrar continuidad y control.

APLICACIÓN PRÁCTICA: Registro de responsables, fechas y transferencias.

[ SECCIÓN 08 ]

Caso Práctico

ESTADO: DOCUMENTADO

[ CASO PRÁCTICO ]

Incidente

==================

Se detectó actividad sospechosa en una notebook corporativa utilizada para la gestión de clientes. El análisis preliminar indicó conexiones remotas fuera del horario habitual de trabajo y accesos a directorios sensibles.

Evidencia recolectada

==================

  • Disco SSD principal.
  • Memoria RAM.
  • Registros de eventos.
  • Historial de conexiones.

Procedimiento de adquisición

==================

  1. Identificación del dispositivo.
  2. Documentación fotográfica.
  3. Cálculo de hash inicial.
  4. Imagen forense bit a bit.
  5. Verificación de integridad.
  6. Almacenamiento seguro.

Resultado

==================

La evidencia fue preservada correctamente y quedó disponible para análisis técnico sin alterar el soporte original.
